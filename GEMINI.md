# Muebles Paty Android Application - Project Overview

This document provides an overview of the "Muebles Paty" Android application, generated by Gemini for instructional context.

## Project Overview

"Muebles Paty" is an Android application developed using Kotlin and Gradle. Its core functionality revolves around providing an e-commerce experience, deeply integrated with Shopify. The application allows users to browse product catalogs, manage a shopping cart, and proceed through a checkout process. It leverages the Shopify Mobile Buy SDK for data fetching (e.g., product listings) and the Shopify Checkout Sheet Kit for handling the checkout flow. Image loading is managed by the Glide library.

## Building and Running

This project is a standard Android application built with Gradle.

*   **Prerequisites:**
    *   Java Development Kit (JDK) 17 or higher.
    *   Android SDK.
*   **Build Commands:**
    *   To build the debug APK: `./gradlew assembleDebug`
    *   To build the release APK: `./gradlew assembleRelease`
*   **Running the Application:**
    *   The application can be run on an Android emulator or a physical device directly from Android Studio.
    *   Alternatively, after building, the generated APK can be installed using ADB:
        `adb install app/build/outputs/apk/debug/app-debug.apk` (for debug builds)

*   **Primary Language:** Kotlin.

*   **Build System:** Gradle, utilizing the Kotlin DSL (`.kts` files) for build scripts.
*   **Application Structure:** Follows a conventional Android activity-based architecture. A custom `MueblesPatyApplication` class is used for global application-level setup and initialization.
*   **Shopify Integration:**

*   **Dependencies:** Key dependencies include `androidx` libraries, `material` design components, `com.shopify.mobilebuysdk`, `com.shopify:checkout-sheet-kit`, and `com.github.bumptech.glide`.
